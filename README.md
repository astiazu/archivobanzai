# Archivo BanZai — frontend v0.1

Primer prototipo visual del sitio histórico de BanZai.

## Incluye

- Hero editorial con los dos logos suministrados.
- Historia / línea de tiempo.
- Concepto de BanZai Radio con playlists por década y estilo.
- Álbum de recuerdos.
- Testimonios.
- CTA "¿Vos también estuviste ahí?"
- Modal de carga de recuerdos como demo frontend.
- Diseño responsive.

## Ejecutar

No necesita Node ni servidor para esta versión.

Abrir `index.html` en el navegador.
